# Employee Lifecycle Automation

A multi-agent AI system that automates employee onboarding.

## Features

- Planner Agent
- Email Agent
- Access Agent
- Training Agent
- Manager Approval Agent

## Architecture

```text
Employee Form
      ↓
Planner Agent
      ↓
Email Agent
      ↓
Access Agent
      ↓
Training Agent
      ↓
Manager Approval Agent
      ↓
Dashboard
```

## Tech Stack

- FastAPI
- SQLite
- HTML
- CSS
- JavaScript
- Claude API

## Run Locally

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```
